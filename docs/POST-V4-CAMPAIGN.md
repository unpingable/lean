## The cluster before v5

v5 (custody-preserving normalization) is deliberately NOT next. Normalization
should only be attempted once the skeleton already knows that time steps
narrow scope, derived evidence inherits caveats, and confidence is not
evidence currency — otherwise v5 normalizes a skeleton missing three attack
surfaces.

## Fable queue (design compression, theorem-shape selection)

- **F1 — Δt as derivation step** (deepest; loops back to the framework's
  original animal). Time passing is an evidence-derivation step that can only
  narrow funding scope. Target shapes: aging never widens funding; stale
  evidence cannot fund demanding use; refresh-by-derivation inexpressible;
  Δt does not create authority.
- **F2 — Fluency as evidence-currency attack** (sharpest application). Model
  confidence/fluency as a candidate `UniversalStamp`: one evidence shape
  offered to fund every reliance bridge. Formalizes HighConfidence ⊬ MayRely /
  Recall ⊬ Reliance through the v4 screen.
- **F3 — Caveat inheritance / burden preservation** (closes the parked 4th
  refusal slice). Derived evidence inherits the caveats/burdens/scope limits
  of its origin; caveat restriction as funding-scope restriction.
- **F4 — AG audit checklist from the v4 screens** (constellation value, no
  runtime claims): does any receipt kind fund every gate; any
  UniversalCrossroads in the NQ→AG flow; does linearaccountant match the
  linear read policy; do refusal objects display without becoming
  consumer-legible. Fable drafts; AG-session/codex applies.
- **F5 — Watchlist zoo template** (cage schema: FORBIDDEN specimen, attack
  shape, screen theorem, false-positive/negative caveats, expected refusal).
  Fable designs the schema once; codex populates.
